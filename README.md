# ColorLab | Color Palette Generator

A web application developed with **Python and Streamlit** that extracts dominant colors from images and generates harmonious color palettes using fundamental algorithms.

## Features

- Extract the five most dominant colors from images.
- Generate harmonious color palettes.
- Display RGB, HEX codes, and color percentages.
- Interactive color wheel visualization.
- Export palettes in CSS and JSON formats.

## Algorithms

- **Bubble Sort:** Sorts colors by pixel frequency.
- **Dynamic Programming:** Selects harmonious color combinations.
- **BFS:** Explores a graph of 12 color hues.

## Technologies

Python · Streamlit · Pillow · HTML · CSS

## Installation

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
